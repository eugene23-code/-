# 사이로그 (SaiLog)

PB와 고객 **사이**를 계좌·시세 **로그**로 잇는 유진투자증권 PB 서비스 프로토타입입니다.

> **시연용 가상 화면입니다.** 고객과 상품은 모두 가상 데이터이며, 실제 종목 추천이나 수익 보장, 투자 권유를 뜻하지 않습니다.

## 화면

| 파일 | 내용 |
|---|---|
| `index.html` | PB 워크스페이스 (오늘 할 일 · 고객 · 알림톡 · 일정 · 인사이트) |
| `alimtalk.html` | 고객에게 가는 카카오 알림톡 예시 |
| `customer.html` | 고객이 보는 화면 시연 |
| `landing.html` | 서비스 소개 |

## 실행

빌드 없이 정적 파일로 동작합니다. `index.html`을 브라우저로 열거나, GitHub Pages로 배포하면 됩니다.

## 시세 데이터

`market/collect.ps1`을 실행하면 실제 시세로 `market.js`를 다시 만듭니다. 출처는 KR 네이버금융, US yfinance입니다. 자세한 내용은 `market/README.md`에 있습니다.
